# kalaśa

`trm:kalasa` · `skeleton` · confidence moderate

**Language:** Sanskrit
**Native script:** कलश
**Literal:** pot, vessel

## Definitions by tradition
- [Mantramārga (the Path of Mantras)](../lineages/mantramarga.md): A consecrated water-pot in which the deity is invoked for bathing and installation rites.
- [Kerala tantra (temple-tantra tradition of Kerala)](../lineages/kerala-tantra.md): Kalaśa rites (e.g. sahasrakalaśa) by which the tantri renews an installed deity's power.

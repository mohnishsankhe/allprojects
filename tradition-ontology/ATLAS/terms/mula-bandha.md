# mūlabandha

`trm:mula-bandha` · `skeleton` · confidence high

**Language:** Sanskrit
**Native script:** मूलबन्ध
**Literal:** root lock

## Definitions by tradition
- [Haṭha Yoga (the haṭha and rājayoga textual tradition)](../lineages/hatha-yoga.md): Contracting the root so that apāna rises; by it prāṇa and apāna, nāda and bindu become one (HYP 3.61–65).
- [Nāth tradition (Nātha Siddhas; Nāth / Kānphaṭa Yogīs)](../lineages/natha.md): The root lock drawing apāna upward (GŚ 37).

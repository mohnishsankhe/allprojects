# anekāntavāda

`trm:anekantavada` · `skeleton` · confidence moderate

**Language:** Sanskrit
**Native script:** अनेकान्तवाद
**Literal:** doctrine of non-one-sidedness

## Definitions by tradition
- [Jainism (Jaina dharma)](../lineages/jainism.md): The doctrine that reality has infinite aspects (e.g. permanent as substance, impermanent as modes), so that every statement is true only in some respect (TS 5.30–32; Āptamīmāṃsā).

# Karma without own-nature

`cpt:karma-without-svabhava` · `skeleton` · confidence moderate

**Category:** karma-rebirth

## Names

## Definitions
- [Madhyamaka](../lineages/madhyamaka.md): Action is intention and intended action (MMK 17.2–3); if it lasted until ripening it would be permanent, if it perished it could bear no fruit (17.6); because it is without own-nature it is unarisen and so does not perish (17.21); agent and action are like emanations (17.31–33).
- [Prāsaṅgika-Madhyamaka](../lineages/prasangika.md): Agent and enjoyer are spoken of with reference to the unity of a continuum (BCA 9.73); the Mādhyamika does not deny action and fruit but their own-nature (PsP 17.30).

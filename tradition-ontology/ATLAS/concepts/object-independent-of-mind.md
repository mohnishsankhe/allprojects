# The object is independent of any one mind (4.15-4.16)

## Names
- [Pātañjala Yoga (the Yoga darśana)](../lineages/patanjala-yoga.md): The object is independent of any one mind (4.15-4.16)

## Definitions
- [Pātañjala Yoga (the Yoga darśana)](../lineages/patanjala-yoga.md): With the object the same, minds differ (4.15); the object does not depend on a single mind (4.16); it is common to all puruṣas, and minds work separately in each puruṣa, from whose connection apprehension arises (bhāṣya 4.16).
- [Pātañjala Yoga (the Yoga darśana)](../lineages/patanjala-yoga.md): A thing is common to many minds and stands on its own (4.14–16): the same thing produces pleasure, pain, delusion or indifference in different minds (YBh 4.15); if it depended on one mind, what would it be when that mind was distracted? (4.16); it is known or unknown as it colours the mind (4.17). Vyāsa rejects those who say the object is only a construction of cognition, like a dream (YBh 4.14), and those who say 'all is mind only' (YBh 4.23).

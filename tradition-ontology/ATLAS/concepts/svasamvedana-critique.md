# Reflexive awareness: accepted or refuted

`cpt:svasamvedana-critique` · `skeleton` · confidence moderate

**Category:** mind

## Names
- [Madhyamaka](../lineages/madhyamaka.md): svasaṃvedana

## Definitions
- [Yogācāra-Madhyamaka](../lineages/yogacara-madhyamaka.md): Consciousness is self-illuminating because it is not inert; accepted conventionally (MAL 16–17).
- [Prāsaṅgika-Madhyamaka](../lineages/prasangika.md): Refuted: mind does not see mind, as a blade does not cut itself (BCA 9.17ff); memory does not prove reflexive awareness (MA 6.72–77).

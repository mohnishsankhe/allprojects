# Purandara (Cārvāka)

`tch:purandara-carvaka` · `skeleton` · confidence high

**Alternate names:** Purandara
**Lineages:** [Cārvāka / Lokāyata](../lineages/carvaka.md)
**Dates:** Scholarly account: c. 7th c. CE; (confidence low)
**Historicity:** historical

A Cārvāka author quoted by Kamalaśīla: 'the Cārvākas too accept inference as known in the world; what is rejected is inference that some state by transgressing the worldly path' (Tattvasaṅgraha-pañjikā on 1481–82).
